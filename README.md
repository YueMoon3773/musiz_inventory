
## 🎵 The Muziz Library

A full-stack **music library management application** that allows users to browse, create, update, and organize songs, artists, and genres with a clean UI and theme support.

Built to demonstrate real-world CRUD operations, RESTful APIs, and modern frontend-backend integration.


## 📖 Introduction
**The Muziz Library** is a full-stack web application designed to manage a structured music collection.

Users can view songs with their associated artists and genres, perform full CRUD operations, search across entities, and switch between light and dark themes for a better user experience.

This project focuses on data relationships, API-driven UI, and clean application architecture.
## ✨ Features

- Light/dark mode toggle.
- Create new songs, artists, and genres.
- Edit existing songs, artists, and genres.
- Delete songs, artists, and genres.
- Dynamic sorting (ascending / descending).
- Search songs, artists, and genres by keyword.
- Song details view with linked artists and genres


## 🧠 Tech Stack

**Frontend**
- React
- CSS / SCSS

**Backend**
- Node.js/Express.js
- CRUD operations
- Controller / Route separation

**Database**
- PostgreSQL
- Relational data modeling

**Tools & Workflow**
- Git & GitHub
- npm
- Environment variables


## 🎯 Project Purposes

This project was built to:
- Practice full CRUD functionality across multiple related entities.
- Strengthen understanding of REST APIs and client-server communication.
- Work with relational databases and data normalization.
- Improve React state management and routing.
- Implement theme toggling and UI consistency.
- Simulate a real production-style full-stack app.
